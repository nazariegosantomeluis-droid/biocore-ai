# Tipografías de BIOCORE AI

Empaquetadas en el repo para que la app se vea igual **sin internet**
(Modo Rural): Streamlit las sirve desde `app/static/` (`server.enableStaticServing`
en `.streamlit/config.toml`).

| Archivo | Familia | Uso | Origen |
|---|---|---|---|
| `figtree-latin-wght-normal.woff2`, `figtree-latin-ext-wght-normal.woff2` | Figtree (variable 300–900) | títulos | `@fontsource-variable/figtree` 5.3.0 |
| `noto-sans-latin-wght-normal.woff2`, `noto-sans-latin-wght-italic.woff2` | Noto Sans (variable 100–900) | texto | `@fontsource-variable/noto-sans` 5.3.0 |
| `noto-sans-greek-wght-normal.woff2` | Noto Sans, griego | α β θ δ γ Δ del EEG y fórmulas | ídem |

Elegidas con la guía de diseño UI UX Pro Max (estilo "Accessible & Ethical"
para salud). Ambas tienen licencia SIL Open Font License 1.1: ver
`LICENSE-Figtree-OFL.txt` y `LICENSE-NotoSans-OFL.txt`. Se pueden
redistribuir con la app; no se pueden vender por separado.
